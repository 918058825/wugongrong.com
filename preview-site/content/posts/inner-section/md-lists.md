## 列表

Markdown 支持有序列表、无序列表和多层嵌套列表，适合清楚地整理步骤与要点。

### 有序列表

1. 准备所需材料
2. 按照步骤完成操作
3. 检查最终结果

### 无序列表

- 简洁明了
- 层次清楚
- 便于浏览

### 多层无序列表

- 水果
  - 苹果
  - 橙子
- 乳制品
  - 牛奶
  - 奶酪

### 多层有序列表

1. 准备
   - 确认目标
   - 收集资料
2. 执行
   1. 完成第一步
   2. 完成第二步

### 混合嵌套列表

1. 第一项
   - 补充说明
2. 第二项
   1. 子步骤一
      - 进一步说明
   2. 子步骤二
3. 第三项
   - 补充说明

### 列表中的段落、代码和引用

- 列表项也可以包含一段说明文字。

- 代码示例：

  ```javascript
  function greet(name) {
    return `你好，${name}！`;
  }
  ```

- 引用内容：
  > 清晰的列表能让复杂信息更容易理解。
